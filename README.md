# minecraft-bot-admin
Bot for Minecraft server administration

# Possibilitie
You will be able to send commands to the console via the bot using RCON.



# How to use?
Requirements:
> Python 3.13
>
>  pip install mcron
> 
> pip install telebot

Specify the server IP, password, and port in rcon.py.

Provide the bot API token and your Telegram ID in Bot.py.
